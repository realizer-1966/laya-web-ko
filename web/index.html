Laya 브라우저 데모 — 한국어

다국어 Laya 결정 모델(mmBERT-base, 322M, 100개 이상 언어)을 ONNX Runtime Web으로 이 페이지 안에서만 실행합니다. 입력한 내용은 절대 페이지 밖으로 나가지 않습니다.

1 · 모델 로드

아직 로드하지 않았습니다. 로드 시 이 사이트에서 모델 파일을 내려받습니다(수백 MB, 방문당 1회).

2 · 타입 질문 던지기

테스트 데이터 더 보기 (라벨링된 케이스 108개)

질문 타입: choice (라벨 선택), score (순서 척도), noul (예/아니오 확률). 다국어 체크포인트 기준 선택지 약 20개, 상태 최대 1024 토큰.

결과

–추론 시간 (ms)
–입력 토큰 (전체 질문 합계)
–백엔드
원시 JSON

  


  

    
3 · 원본 PyTorch 모델과 대조

    
저장된 테스트 케이스 6개를 이 브라우저에서 실행해, 같은 입력에 대해 원본 fp32 PyTorch 모델이 낸 확률과 비교합니다. 양자화 때문에 숫자는 조금씩 달라지므로, 신뢰도 값을 믿기 전에 차이가 얼마나 되는지 확인하는 용도입니다.
